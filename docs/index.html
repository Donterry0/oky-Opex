oky-Opex

Broker platform documentation — free-tier hosting on Render, Firebase, and GitHub Pages.

Architecture

oky-Opex is a full-stack Next.js application. It is deployed as a single service on Render (free tier), backed by Firebase (Authentication + Firestore/Realtime Database, free tier) for user accounts and application data. This site is published to GitHub Pages and only contains static documentation — the live application itself runs on Render.

Public site

Landing page, markets, assets, and support pages for visitors.

Admin panel

Authenticated dashboard for managing users, KYC, withdrawals, balances, and audit logs.

Firebase

Handles authentication and stores application data on the free tier.

Deployment guide

  1. Fork/clone the repository.
  2. Create a Firebase project and enable Authentication + Firestore (see FIREBASE_SETUP.md).
  3. Create a new Render Web Service from this repo — Render will detect render.yaml and provision the free-tier service automatically.
  4. Set the environment variables listed in .env.example in the Render dashboard.
  5. Push to main — the Deploy to Render GitHub Actions workflow validates the build and Render auto-deploys.

Environment variables

All required variables are documented in .env.example in the repository root, including:

DATABASE_URL
FIREBASE_PROJECT_ID / FIREBASE_CLIENT_EMAIL / FIREBASE_PRIVATE_KEY
NEXT_PUBLIC_FIREBASE_*  (client SDK config)
NEXTAUTH_SECRET / JWT_SECRET
ADMIN_EMAIL / ADMIN_PASSWORD
NEXT_PUBLIC_APP_URL
